# Superb Input Precision

## What does it do?

This mod lets your inputs register at a higher precision than vanilla, while still aiming to replicate its physics. (See the GitHub README for an explanation of how CBF and CBS affect physics, and how this mod works.)

Please note: while the goal is vanilla-accurate physics, higher input precision beyond what Click Between Steps offers is not vanilla, and likely never will be unless RobTop updates it again. As such, there is also no objective "correct" way to achieve higher input precision. Even RobTop's CBS uses the same method as CBF, so one may argue that CBF is more vanilla than SIP. This mod may be considered cheating, so use at your own risk.
